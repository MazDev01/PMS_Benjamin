# ตารางเทียบ flow กับระบบ — รอบที่ 1 (ตรวจอย่างเดียว · 19 ต.ค. 69)

ต้นฉบับ flow = `docs/FLOW.html` (อัปเดตรอบนี้: ขั้นต่อขั้นของ HQ และดีลเลอร์ + การตัดสินใจ 0201–0205 · 0214 · 0215 · ไม่มีแม่แบบ · เข้าด้วยรหัสสาขา · ไม่มีลืมรหัส · ไม่มีหน้าบังคับ)

**เว็บจริงรันโค้ดอะไร:** ทั้ง pms. และ dealerpms. รัน c5e360a = GitHub = โค้ดในเครื่อง (ตรวจหลัง push วันนี้) → ที่บอสเห็นแบบเก่าคือของที่ยังอยู่ในโค้ดจริง ไม่ใช่เว็บค้าง

**วิธีตรวจ:** อ่านโค้ดทุกหน้า ทุกเมนู ทุกปุ่ม ทั้งสองแอป + ฐานข้อมูล (ใบล่าสุดถึง 0215) · ข้อที่สำคัญตรวจซ้ำด้วยตัวเองแล้ว · ไม่ได้เปิดเว็บจริงด้วยบัญชีจริง เพราะเว็บจริง = โค้ดในเครื่องทุกตัวอักษร

ผล: **ตรง** = ตาม flow · **ต่าง** = มีแต่ทำไม่ตรง · **ไม่มี** = flow บอกให้มีแต่ยังไม่มี · **เก่า** = ของเก่าที่ต้องเอาออก · **ตัดสิน** = flow ไม่ได้บอก หรือขัดกับคำสั่งเดิมของบอส ต้องให้บอสเลือก

## ค. เรื่องที่ต้องให้บอสตัดสินก่อนรอบ 2

1. **แถว "HQ" ในทะเบียนดีลเลอร์** — ตอนนี้ตรึงบนสุดตามที่บอสสั่ง 7 ก.ย. 69 แต่ได้ปุ่มลบ และถูกนับเป็นดีลเลอร์ในแดชบอร์ด/ภาพรวม/เป้ารวม
   ทางเลือก: (ก) ซ่อนจากทุกรายการและการนับ เหลือไว้เป็นเจ้าของลีดของ HQ อย่างเดียว (ข) แสดงแยกเป็นแถวพิเศษ ไม่มีปุ่มลบ/ปิดใช้งาน ไม่นับในสถิติ
2. **ปุ่มในแถวทะเบียนดีลเลอร์ (5 ปุ่ม) และปุ่ม "ลบ" ดีลเลอร์** — flow ไม่มีขั้นลบดีลเลอร์
   ทางเลือก: (ก) เหลือ "เข้าระบบ" + "ดูรายละเอียด" ในแถว ที่เหลือย้ายเข้าแผงรายละเอียด และเอาลบออก (ใช้ปิดใช้งานแทน) (ข) เก็บลบไว้ในแผงรายละเอียด
3. **ดีลเลอร์ "เปิดใหม่" ลีดที่ปิดการขายสำเร็จ** — ขัดกับ "ย้อนการตอบรับได้เฉพาะ HQ" · เสนอ: เอาปุ่มออก + ใบปรับฐานกันที่ลีด (ต้องมีใบใหม่)
4. **HQ ย้อนการตอบรับแล้ว ลีดควรเป็นอะไร** — ตอนนี้ลีดค้าง "ปิดการขายสำเร็จ" ทั้งที่ใบกลับเป็นส่งแล้ว · เสนอ: ลีดกลับเป็น "เสนอราคา" (ย้อนเป็นส่งแล้ว) หรือ "ปิดไม่สำเร็จ" (ย้อนเป็นปฏิเสธ) (ต้องมีใบใหม่)
5. **ช่อง "ประเมินราคา" ที่ดีลเลอร์พิมพ์เอง** — ใช้คำนวณ "โอกาสการขาย" · เก็บไว้ (เป็นตัวเลขคาดการณ์ ไม่ใช่ราคา) หรือเอาออก
6. **ลบลีด / ลบลูกค้า / นำเข้าลูกค้าเดิม ของดีลเลอร์** — flow ไม่ได้พูดถึง · ลบลูกค้าไม่มีทางสำเร็จแล้ว (ลูกค้าทุกรายผูกใบที่ตอบรับ) · นำเข้าลูกค้าเดิม ขัดกับ "ดีลเลอร์สร้างลูกค้าเองไม่ได้"
7. **กระดิ่ง** — ดีลเลอร์: ให้มีเรื่อง "HQ ส่งราคาแล้ว" + ตัดประวัติตอบรับ/เสียโอกาสย้อนหลังออก · HQ: ให้เรื่องจากดีลเลอร์ (คำขอใหม่ · ยกเลิก · ขอแก้ราคา · ลูกค้าตอบรับ · เกินกำหนด) เข้ากระดิ่งด้วย หรือคงไว้แค่อีเมล
8. **การ์ดที่ไม่มีข้อมูล** — เสนอ: ทุกการ์ด/แถบที่ยังไม่มีเป้าหรือยังไม่มีตัวหาร ขึ้น "—" แทน 0% (ตามกติกา "ไม่มีข้อมูลให้ขึ้น —") และเอาป้าย "ล้าหลังเป้า" ออกเมื่อยังไม่ตั้งเป้า
