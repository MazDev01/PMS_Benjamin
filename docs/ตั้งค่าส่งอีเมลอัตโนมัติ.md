# ตั้งค่าระบบส่งอีเมลอัตโนมัติ (ระบบจริง)

> สำหรับบอสทำเองทีละคลิก · ใช้เวลาประมาณ 20 นาที · ทำครั้งเดียว
> เขียน 16 ต.ค. 69 · ระบบส่งอีเมลทุก 15 นาทีผ่านตัวตั้งเวลาของฐานข้อมูล (ใบ 0212) แทน Vercel (แผน Hobby ตั้งถี่ไม่ได้)

## ภาพรวม: ใส่ค่าที่ไหนบ้าง

| ที่ | ใส่อะไร | ทำไม |
|---|---|---|
| Vercel โปรเจกต์ **benjamin-hq** เท่านั้น | `CRON_SECRET` + `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` | เว็บ HQ เป็นตัวส่งอีเมลทุกฉบับ (เว็บดีลเลอร์ส่งคำขอต่อมาที่ HQ) |
| Vercel โปรเจกต์ **benjamin-dealer** | **ไม่ต้องใส่อะไร** | ไม่ได้ส่งอีเมลเอง |
| Supabase ระบบจริง (Vault) | `CRON_SECRET` ค่าเดียวกัน + ที่อยู่ปลายทาง | ตัวตั้งเวลาในฐานต้องแนบรหัสนี้ตอนเรียกเว็บ HQ ไม่งั้นถูกปฏิเสธ |
| หน้าเว็บ HQ › ตั้งค่า › การแจ้งเตือน | อีเมลผู้รับฝั่ง HQ | ตอนนี้ว่าง (0 คน) — คำขอราคาใหม่จะไม่มีใครได้อีเมล |

`CRON_SECRET` ผมสร้างให้แล้ว (ส่งในแชท ไม่เก็บในไฟล์นี้) — **ต้องตรงกันทุกตัวอักษรทั้งที่ Vercel และ Supabase**

## ขั้นที่ 1 — สร้างรหัสแอปของ Gmail (ผู้ให้บริการที่แนะนำ)

**แนะนำ Gmail ของบริษัท** (บัญชี Gmail ธรรมดาหรือ Google Workspace ก็ได้): ตั้งง่ายที่สุด ไม่ต้องยืนยันโดเมน ไม่มีค่าใช้จ่าย
ส่งได้ราววันละ 500 ฉบับ (Workspace ราว 2,000) — ดีลเลอร์ 155 รายเกินไม่ถึง
ถ้าเคยทำตาม [ตั้งค่าอีเมลบริษัท-SMTP.md](ตั้งค่าอีเมลบริษัท-SMTP.md) ไว้แล้ว ใช้บัญชีและรหัสแอปชุดเดียวกันได้เลย ข้ามไปขั้นที่ 2

1. เปิด https://myaccount.google.com/security ด้วยบัญชี Gmail ที่จะใช้ส่ง
2. **การยืนยันแบบ 2 ขั้นตอน** ต้องเป็น **เปิด** (ปิดอยู่ = ไม่มีเมนูรหัสแอป)
3. เปิด https://myaccount.google.com/apppasswords
4. ช่อง **App name** พิมพ์ `Benjamin PMS` → **Create**
5. คัดลอกรหัส 16 ตัว แล้ว **ลบช่องว่างออก** เช่น `abcd efgh ijkl mnop` → `abcdefghijklmnop`

## ขั้นที่ 2 — ใส่ค่าใน Vercel (โปรเจกต์ benjamin-hq)

1. เปิด https://vercel.com → เลือกโปรเจกต์ **benjamin-hq**
2. แท็บ **Settings** → เมนูซ้าย **Environment Variables**
3. เพิ่มทีละตัว (ช่อง **Key** / **Value** · Environments ติ๊ก **Production** อย่างน้อย) → **Save** ทุกตัว

| Key | Value |
|---|---|
| `CRON_SECRET` | ค่าที่ผมส่งในแชท |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | อีเมล Gmail เต็ม ๆ ที่ใช้ส่ง |
| `SMTP_PASS` | รหัสแอป 16 ตัวจากขั้นที่ 1 (ไม่มีช่องว่าง) |
| `SMTP_FROM` | `Benjamin PMS <อีเมลเดียวกับ SMTP_USER>` |

> `SMTP_FROM` ต้องเป็นอีเมลเดียวกับ `SMTP_USER` — Gmail ไม่ให้ส่งในนามอีเมลอื่น

4. แท็บ **Deployments** → รายการบนสุด (Production) → ปุ่ม **⋯** → **Redeploy** → ยืนยัน
   (ค่าใหม่มีผลหลัง Redeploy เท่านั้น) → รอจนเป็น **Ready**

## ขั้นที่ 3 — ลงใบ 0212 (ตัวตั้งเวลาในฐาน)

ในโฟลเดอร์ `C:\.claude\Benjamin-HQ-main` รัน:
```
npm run db:push:prod -- --yes-prod
```
ต้องเห็นใบที่จะลง **1 ใบ (0212)** เท่านั้น — เห็นมากกว่านี้ให้หยุดแล้วส่งผลให้ผม

## ขั้นที่ 4 — ใส่รหัสใน Supabase (Vault)

1. https://supabase.com/dashboard → โปรเจกต์ระบบจริง → เมนูซ้าย **SQL Editor** → **New query**
2. วาง 2 บรรทัดนี้ (แทน `<CRON_SECRET>` ด้วยค่าที่ผมส่งในแชท · คงเครื่องหมาย `'` ไว้) → **Run**
```sql
select vault.create_secret('https://pms.benjaminpebsteel.com/api/cron/send-email', 'cron_send_email_url');
select vault.create_secret('<CRON_SECRET>', 'cron_secret');
```
3. ผลต้องได้รหัสยาว ๆ 2 แถว · ถ้าขึ้นว่าชื่อซ้ำ (already exists) แปลว่าเคยใส่แล้ว — ส่งข้อความนั้นให้ผม

## ขั้นที่ 5 — ใส่อีเมลผู้รับฝั่ง HQ

เว็บ HQ → **ตั้งค่า** → แท็บ **การแจ้งเตือน** → การ์ด **อีเมลผู้รับแจ้งเตือน** → ใส่อีเมล (บรรทัดละ 1 อีเมล)คนที่ต้องได้รับ "คำขอราคาใหม่จากดีลเลอร์" → **บันทึก**

## ขั้นที่ 6 — ส่งข้อความบอกผมว่า "ตั้งเสร็จแล้ว" + อีเมลกล่องทดสอบ 1 อีเมล

ผมจะตรวจต่อเอง (ไม่ต้องส่งค่าใด ๆ มาในแชท):
- ใบ 0212 ลงแล้ว · สิทธิ์ตรงกับในโค้ด · มีงานตั้งเวลา `send-email` ทุก 15 นาที
- รอบตั้งเวลาถัดไปเรียกเว็บ HQ สำเร็จ (รหัสไม่ตรง = ถูกปฏิเสธ จะเห็นทันที)
- ส่งอีเมลทดสอบจริง 1 ฉบับถึงกล่องทดสอบ → บอสยืนยันว่าได้รับ
- ผ่านแล้วจึงตั้งเครื่องหมาย "ต้องเปลี่ยนรหัส" ให้บัญชีดีลเลอร์

## ถ้ามีปัญหา
- **ส่งไม่ออก ขึ้นว่ารหัสผิด (535):** รหัสแอปผิด หรือยังมีช่องว่าง → สร้างรหัสแอปใหม่ แก้ `SMTP_PASS` แล้ว Redeploy
- **ไม่อยากให้ส่งชั่วคราว:** ลบแถว `cron_secret` ใน Vault (`delete from vault.secrets where name = 'cron_secret';`) — ตัวตั้งเวลาจะข้ามเงียบ ๆ จดหมายรอในกล่องขาออก
