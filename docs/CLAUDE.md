## รอบตรวจเต็มต้องได้คำอนุมัติของบอส (บอสสั่ง 5 พ.ย. 69)

- ไม่มีตัดรอบอัตโนมัติ (เลิกตัดรอบ 16:30)
- ระหว่างวัน: แก้แล้วรันแค่ข้อทดสอบของส่วนที่ตัวเองแก้ (`npm run test:prodbuild -- <ไฟล์>`) แล้วเพิ่มงานเข้ารายการรอรอบ
  `npm run round:add -- --งาน "<ข้อความ>" --เซสชัน <ชื่อ> [--ทดสอบผ่าน]` · ตั้งผ่านภายหลัง `npm run round:pass -- --รหัส <id>`
- ห้ามเซสชันรันรอบตรวจเต็มเอง (`npm run test:prodbuild` ไม่ระบุไฟล์ / `PMS_GATE_FULL=1`)
- ก่อนรอบเต็มทุกครั้ง คนรวมงานถามบอสด้วยกล่องคำถาม — ข้อมูลจาก `npm run round:list`: รายการงานในรอบ · งานที่ยังไม่เสร็จ · ต้อง db:push ไหม · ตรวจเสร็จกี่โมง · ตัวเลือก "ตรวจเลย" / "รอเพิ่มงานก่อน" · ไม่ตอบ = ไม่ตรวจ
- บอสตอบ "ตรวจเลย" → `npm run round:close -- --บอสตอบ "<เวลา>"` (ตัดงานที่ยังไม่ผ่านด้วย `--ตัด <id>`) แล้วค่อยรันรอบเต็ม
- รอบเต็มไม่เริ่มถ้า: ยังไม่ปิดรอบ · รายการเปลี่ยนหลังปิด · รอบนั้นผ่านไปแล้ว — ไม่มีทางข้าม · ชุดงานเปลี่ยน = `round:cancel -- --เหตุ "…"` แล้วถามบอสใหม่
- ข้อยกเว้น: บั๊กเว็บจริงที่ทำข้อมูลเสีย ถามบอสทันที ไม่รอรวมรอบ — ปิดรอบด้วยคำสั่งเดียวกัน ใส่ `--เร่งด่วน`
- ที่เก็บกลาง `C:/.claude/pms-round` (ทุกโฟลเดอร์เซสชันเห็นตรงกัน) · ตัวกัน `scripts/lib/roundQueue.mjs` · ข้อทดสอบ `tests/tools/round-queue.test.mjs`
