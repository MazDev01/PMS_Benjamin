# ช่วงที่ 2 · ซ้อมขึ้นระบบบน "สำเนาข้อมูลจริง" (ก่อนขึ้นระบบจริง ข้อ 12)

> เตรียม 15 ต.ค. 69 · บอสทำตามทีละข้อ → ส่งคำว่า "พร้อมแล้ว" + commit บน Vercel → ผมรันซ้อม → รายงานเป็นตัวเลขอย่างเดียว
> ระบบจริงไม่ถูกแก้อะไรเลยในช่วงนี้ — ทุกอย่างทำบนโปรเจกต์ Supabase แยกที่สร้างขึ้นใหม่ แล้วลบทิ้งหลังจบ

## ก่อนเริ่ม: ต้องรู้ 2 เรื่อง

1. **ระบบจริงไม่มีชุดสำรองของผู้ให้บริการ** (ตรวจไว้ 7 ส.ค. 69: ย้อนเวลา PITR ปิด · ชุดสำรอง 0 ชุด — ดู [BACKUP.md](BACKUP.md))
   ปุ่ม "Restore to a new project" ของ Supabase จึง**น่าจะใช้ไม่ได้** — ข้อ 1 ด้านล่างให้ดูก่อนว่าตอนนี้มีหรือยัง
2. ชุดสำรองของเราเอง (`npm run backup` / สำรองอัตโนมัติ 02:00) เก็บข้อมูลธุรกิจ 23 ตาราง แต่**ไม่มีรหัสผ่านผู้ใช้**
   และสคริปต์กู้คืน (`restore.mjs`) กู้ได้แค่กลับเข้าฐานเดิม — ถ้าต้องใช้ทางนี้ ผมต้องเขียนสคริปต์เพิ่ม (ดูทาง C · **รออนุมัติ**)

---

## ข้อ 1 · ดูว่ามีปุ่มกู้เป็นโปรเจกต์ใหม่หรือไม่ (ทาง A)

1. เข้า https://supabase.com/dashboard → เลือกโปรเจกต์ **ระบบจริง**
2. เมนูซ้าย **Database** → **Backups**
3. ดูว่ามีรายการสำรอง (Scheduled backups / Point in time) และมีปุ่ม **Restore to a new project** หรือไม่
   - **มี** → ทำ "ทาง A" (ข้อ 2A) · **ไม่มี / รายการว่าง** → ข้ามไป "ทาง C" (ข้อ 2C)

## ข้อ 2A · ทาง A: กู้เป็นโปรเจกต์ใหม่จากหน้าเว็บ (ถ้ามีปุ่ม)

1. ในหน้า Backups กด **Restore to a new project** ที่รายการล่าสุด
2. ตั้งชื่อโปรเจกต์ **`pms-rehearsal`** · Region **เดียวกับระบบจริง** · ตั้งรหัสผ่านฐานใหม่ (กด Generate แล้วเก็บไว้ในที่เก็บรหัสผ่าน)
3. กดยืนยัน รอจนสถานะเป็น **Active / Healthy** (หลายนาทีถึงชั่วโมงตามขนาด)
4. ไปข้อ 3

## ข้อ 2C · ทาง C: คัดลอกระบบจริงเข้าโปรเจกต์ใหม่ (ถ้าไม่มีปุ่ม) — ⛔ รออนุมัติ

ทางนี้ต้องมีสคริปต์ที่ยังไม่มี: **อ่านอย่างเดียว**จากระบบจริง (`pg_dump` โครง + ข้อมูล + รายชื่อบัญชี) → ลงโปรเจกต์ใหม่
ผมจะเขียนและซ้อมกับฐานในเครื่องให้ผ่านก่อน แล้วค่อยให้บอสรัน (บอสใส่ที่อยู่ฐานจริงตอนรัน ไม่เก็บในไฟล์)
ระหว่างรอ ทำข้อ 2C-1 ไว้ได้:

**2C-1 สร้างโปรเจกต์เปล่า**
1. https://supabase.com/dashboard → **New project**
2. Organization: องค์กรเดียวกับระบบจริง · Name: **`pms-rehearsal`**
3. Database Password: กด **Generate a password** → คัดลอกเก็บไว้ในที่เก็บรหัสผ่าน (ต้องใช้ในข้อ 3)
4. Region: **เดียวกับระบบจริง** (ดูที่ระบบจริง → Project Settings → General → Region)
5. กด **Create new project** → รอจนสถานะ Healthy (~2 นาที)
   - ถ้าขึ้นว่าองค์กรนี้มีโปรเจกต์ฟรีครบโควตาแล้ว: ต้องหยุดโปรเจกต์อื่นชั่วคราว หรือสร้างในองค์กรอื่น — แจ้งผมก่อนตัดสิน

## ข้อ 3 · ส่งค่าเชื่อมต่อของโปรเจกต์สำเนาให้สคริปต์ (ไม่ต้องส่งในแชท)

1. โปรเจกต์ **`pms-rehearsal`** → **Project Settings** → **API**
   - คัดลอก **Project URL** · **anon public** key · **service_role** key (กด Reveal)
2. ปุ่ม **Connect** (บนสุดของหน้าโปรเจกต์) → แท็บ **Connection string** → เลือก **Session pooler** → คัดลอก URI
   แล้วแทน `[YOUR-PASSWORD]` ด้วยรหัสผ่านฐานจากข้อ 2A/2C-1
3. สร้างไฟล์ **`C:\.claude\Benjamin-HQ-main\.env.rehearsal.local`** (ไฟล์นี้ไม่ขึ้น git — กฎ `.env*`) ใส่ 4 บรรทัด:
   ```
   NEXT_PUBLIC_SUPABASE_URL=<Project URL>
   NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon public>
   SUPABASE_SERVICE_ROLE_KEY=<service_role>
   REHEARSAL_DB_URL=<URI จาก Session pooler ที่ใส่รหัสผ่านแล้ว>
   ```
4. **ตรวจให้แน่ใจว่าเป็นค่าของ `pms-rehearsal` ไม่ใช่ระบบจริง** (สคริปต์ปฏิเสธเองถ้าชี้ระบบจริง แต่ดูด้วยตาอีกชั้น)
5. ส่งข้อความมาว่า **"พร้อมแล้ว"** + **commit บน Vercel Production (7 ตัว)** — ห้ามส่งค่าในไฟล์มาในแชท

## ข้อ 4 · ผมรันซ้อม (บอสไม่ต้องทำอะไร)

```
node scripts/rehearse-go-live.mjs --old-ref <commit บน Vercel>
```
6 ขั้น — ทุกขั้นพิมพ์ตัวเลข/รหัสอย่างเดียว ไม่พิมพ์ชื่อ อีเมล เบอร์ หรือรหัสดีลเลอร์:
1. นับข้อมูลก่อน (10 ตาราง) 2. ลงใบที่ยังไม่มี (คาด 0182–0211 · 30 ใบ) — ใบล้ม = ชื่อใบ + ข้อความ error แล้วหยุด
3. นับข้อมูลหลัง (ต้องเท่าเดิม) 4. ตรวจสิทธิ์จริงเทียบใบ (ต้อง 0 จุด) 5. smoke โค้ดใหม่ (ต้องตก 0)
6. smoke-old โค้ดรุ่นบนระบบจริง + ฐานใหม่: ล็อกอิน · ดูลีด · แก้ลีด · สร้างใบ
   (ซ้อมตัวสคริปต์ในเครื่อง: "สร้างใบ" พัง `hq_quote_required` → วันจริงต้องลงฐาน+โค้ดติดกันในช่วงปิดปรับปรุง)
- บัญชีที่สคริปต์สร้างบนสำเนาเป็นบัญชีชั่วคราว ลบทิ้งเองหลังจบ · ปิดการส่งอีเมลระหว่างซ้อม

**รายงานที่บอสจะได้:** ตัวเลขทั้ง 6 ขั้น + ผ่าน/ไม่ผ่าน + ข้อเสนอว่าวันจริงต้องทำอะไรเพิ่ม

## ข้อ 5 · หลังซ้อมจบ: ลบโปรเจกต์สำเนา (มีข้อมูลลูกค้าจริง)

1. `pms-rehearsal` → **Project Settings** → **General** → เลื่อนล่างสุด **Delete project** → พิมพ์ชื่อยืนยัน
2. ลบไฟล์ `C:\.claude\Benjamin-HQ-main\.env.rehearsal.local`
