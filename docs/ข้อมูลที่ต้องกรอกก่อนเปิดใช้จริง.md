# ข้อมูลที่ต้องได้ก่อนเปิดให้ตัวแทนใช้งาน

ตรวจสภาพฐานข้อมูลจริงเมื่อ 14 สิงหาคม 2569

> ระบบพร้อมทางเทคนิคครบแล้ว (ตรวจผ่านทุกข้อ) — ที่เหลือคือ **ข้อมูลของธุรกิจ**
> ซึ่งต้องมาจากทางเบนจามินเท่านั้น ระบบเดาหรือใส่ตัวเลขสมมติแทนไม่ได้
> กรอกครบแล้วเปิดใช้ได้ทันที ไม่ต้องแก้โปรแกรมอะไรเพิ่ม

---

## 1. ราคากลางแม่แบบ — ไม่ต้องกรอกแล้ว

แม่แบบเอาออกจากระบบแล้ว (16 ต.ค. 69) — สำนักงานใหญ่พิมพ์ต้นทุนเองในใบ HQ ทีละงาน (ชื่อ · จำนวน · หน่วย · ต้นทุน)

---

## 3. รายชื่อตัวแทนจำหน่าย ⛔

**ตอนนี้ในระบบมีตัวแทน 0 ราย**

ต่อ 1 ราย ต้องการ:

| ข้อมูล | ตัวอย่าง |
|---|---|
| รหัสตัวแทน (2–5 ตัวอักษรอังกฤษ) | `CNX` |
| ชื่อตัวแทน/บริษัท | บจ. เชียงใหม่สตีลบิลด์ |
| จังหวัด + ภาค | เชียงใหม่ · ภาคเหนือ |
| เป้ายอดขายรายปี | ฿____ |

- ระบบสร้าง **บัญชีเข้าระบบให้อัตโนมัติ** ตอนตั้งลูกค้าเป้าหมายเป็นตัวแทน แล้วแสดงอีเมล+รหัสผ่านให้คัดลอกไปแจ้ง (ส่งทางช่องทางที่ปลอดภัย)
- กติกา: **1 ตัวแทน = 1 บัญชี** (ทุกคนในสาขาใช้บัญชีเดียวกัน)
- กรอกที่: สำนักงานใหญ่ → **ลูกค้าเป้าหมาย (HQ)** → เปิดรายนั้น → ตั้งเป็นตัวแทนจำหน่าย (สร้างที่หน้าตัวแทนจำหน่ายตรง ๆ ไม่ได้แล้ว)

## 4. เป้ายอดขายรวมทั้งปี ⛔

- ตอนนี้ตั้งไว้ **฿90,000,000**
- ต้องยืนยันว่าใช่ตัวเลขจริงของปีนี้ไหม และควรใกล้เคียงกับผลรวมเป้าของตัวแทนทุกราย
- กรอกที่: สำนักงานใหญ่ → ตั้งค่า → **เป้าหมายยอดขาย**

---

## 5. เรื่องที่ต้องตัดสินใจ (ไม่ใช่ข้อมูล) ⛔

1. **ที่เก็บสำเนาข้อมูลสำรองนอกเครื่อง** — ตอนนี้ไฟล์สำรองอยู่เครื่องเดียวกับระบบ เครื่องพัง = เสียทั้งคู่พร้อมกัน
   ทางเลือก: เปิดบริการสำรองของผู้ให้บริการฐานข้อมูล (ย้อนเวลาได้ มีค่าใช้จ่ายรายเดือน)
2. **เปลี่ยนรหัสผ่านบัญชีผู้ดูแลระบบ** ไม่ให้ซ้ำกับที่ใช้ตอนพัฒนา
3. **ใครดูแลระบบหลังส่งมอบ** และช่องทางแจ้งปัญหา

---

## หลังกรอกครบแล้ว — ขั้นตอนเปิดใช้

1. ทดลองใช้จริงกับตัวแทน 1–2 ราย ตั้งแต่เพิ่มลูกค้าเป้าหมายจนปิดการขาย
2. ให้แต่ละสาขาเข้าไปกรอกข้อมูลบริษัทของตัวเอง (ตั้งค่า → บัญชีดีลเลอร์) — **ไม่กรอก = ใบเสนอราคาไม่มีหัวกระดาษ**
3. อบรมผู้ใช้ด้วยคู่มือ 2 ฉบับใน `docs/` (ฉบับสำนักงานใหญ่ · ฉบับตัวแทนจำหน่าย)
