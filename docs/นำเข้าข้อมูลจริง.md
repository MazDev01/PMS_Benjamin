# นำเข้าข้อมูลจริงเข้าระบบ Benjamin PMS

ใช้ตอนเปิดใช้งานจริง — ยังไม่ต้องมีลูกค้าหรือใบเสนอราคา ขอแค่ 2 อย่างนี้ก่อน (ราคากลางแม่แบบไม่ต้องแล้ว — เอาแม่แบบออกทั้งระบบ 16 ต.ค. 69)

## 1. ให้ทางบริษัทกรอก 2 ไฟล์

คัดลอกไฟล์ตัวอย่างจาก `docs/templates/` แล้วส่งให้กรอก (เปิดด้วย Excel ได้เลย)

| ไฟล์ | กรอกอะไร |
|---|---|
| `สาขา.csv` | รหัสสาขา 3 ตัวอักษร · ชื่อ · จังหวัด · ภาค · เป้ายอดขายทั้งปี · อีเมลกับรหัสผ่านเข้าระบบ |
| `เป้าบริษัท.csv` | เป้ายอดขายรวมทั้งปี · เป้าอัตราปิดการขาย · เป้าติดตามตรงเวลา |

**ช่องที่เว้นได้:** อีเมล (ระบบตั้งให้เป็น `<รหัสสาขา>@partner-agent.co.th`) และรหัสผ่าน (ระบบสุ่มให้)
**ช่องที่เว้นไม่ได้:** ชื่อสาขา · จังหวัด · เป้ายอดขาย

## 2. ตรวจก่อน (ยังไม่เขียนอะไรลงระบบ)

```bash
node scripts/import-real-data.mjs <โฟลเดอร์ที่เก็บ csv>
```

จะบอกทีละแถวว่าผิดตรงไหน เช่น รหัสสาขาซ้ำ · เป้าติดลบ · อีเมลผิดรูปแบบ
**ถ้ามีปัญหาแม้แต่จุดเดียว จะไม่เขียนอะไรลงระบบเลย** ให้แก้ไฟล์แล้วรันซ้ำจนขึ้น "ข้อมูลผ่านการตรวจทั้งหมด"

## 3. นำเข้าจริง

```bash
node scripts/import-real-data.mjs <โฟลเดอร์ที่เก็บ csv> --เขียนจริง
```

⚠️ ก่อนรัน ดูบรรทัด "ฐานข้อมูลปลายทาง" ที่สคริปต์พิมพ์ออกมา ให้แน่ใจว่าเป็นชุดที่ตั้งใจ
มี 2 ชุด: `yhhhcrvhkforwsagojho` = ของจริง · `fxckixlzsfqalqukhuud` = ชุดทดสอบ

## 4. สร้างบัญชีเข้าระบบให้แต่ละสาขา

สคริปต์จะลงข้อมูลสาขาให้ แต่ **บัญชีเข้าระบบต้องสร้างที่หน้าจอ** เพราะขั้นตอนนั้นต้องผูกบัญชี
เข้ากับระบบยืนยันตัวตนและเก็บสำเนารหัสไว้ให้สำนักงานใหญ่เปิดดูย้อนหลังได้

ไปที่ **สำนักงานใหญ่ › ลูกค้าเป้าหมาย (HQ)** เปิดรายนั้นแล้วกด **ตั้งเป็นตัวแทนจำหน่าย** กรอกอีเมล/รหัสตามไฟล์ที่เตรียมไว้
(สร้างตัวแทนตรง ๆ ไม่ได้แล้ว · สาขาชุดตั้งต้นจำนวนมากใช้ `scripts/seed-dealers.mjs` แทน)

## 5. ตรวจก่อนส่งมอบ

- เข้าระบบด้วยบัญชีของสาขาใดสาขาหนึ่งได้จริง
- เพิ่มลูกค้าเป้าหมาย 1 ราย → ออกใบเสนอราคา 1 ใบ → ปิดการขายได้ครบวง
- แดชบอร์ดสำนักงานใหญ่เห็นยอดของสาขานั้นขึ้นมาจริง

## ก่อนแตะข้อมูลจริงทุกครั้ง — สำรองก่อน

