# คู่มือใช้งานสำหรับดีลเลอร์

> คู่มือนี้เขียนจากระบบจริง ทุกขั้นตอนผ่านการทดลองทำจริงตั้งแต่ต้นจนจบแล้ว
> ฉบับของสำนักงานใหญ่อยู่ที่ [คู่มือสำนักงานใหญ่.md](./คู่มือสำนักงานใหญ่.md)

## 1. เข้าสู่ระบบ

1. เปิดเว็บของดีลเลอร์ (ที่อยู่เว็บสำนักงานใหญ่แจ้งให้)
2. กรอก **อีเมล** และ **รหัสผ่าน** ที่สำนักงานใหญ่ส่งให้ แล้วกด **เข้าสู่ระบบ**

**เรื่องรหัสผ่านที่ต้องรู้**
- 1 ดีลเลอร์ = 1 บัญชี — ทุกคนในสาขาใช้บัญชีเดียวกัน (ระบบออกแบบมาแบบนี้ ไม่ใช่ข้อจำกัด)
- ปิดเบราว์เซอร์แล้วเปิดใหม่ยังอยู่ในระบบ · ถ้าอยู่นิ่งนานระบบจะให้เข้าใหม่เพื่อความปลอดภัย

**ลืมรหัสผ่าน — ติดต่อสำนักงานใหญ่** ให้ตั้งรหัสใหม่ให้ (ที่หน้าเข้าสู่ระบบขึ้นว่า "ลืมรหัสผ่าน ติดต่อ HQ")

> การกู้รหัสเองทางอีเมลปิดไว้ชั่วคราวตั้งแต่ 16 ต.ค. 69 จนกว่าอีเมลเข้าระบบของทุกสาขาจะเป็นอีเมลจริงที่ยืนยันแล้ว

**ดูรหัสผ่านของสาขาตัวเอง** — ปิดไว้ชั่วคราว (ต้องส่งเลขยืนยันทางอีเมล ซึ่งปิดอยู่) · กดแล้วขึ้นว่า "ปิดชั่วคราว ติดต่อ HQ"

**เปลี่ยนรหัสผ่าน** — หน้าเดียวกัน กดปุ่ม **เปลี่ยนรหัสผ่าน** แล้วกรอกรหัสเดิม + รหัสใหม่
ช่องรหัสทุกช่องมีปุ่มรูปตา กดดูสิ่งที่พิมพ์ได้

## 2. สิ่งแรกที่ต้องทำก่อนใช้งานจริง — กรอกข้อมูลบริษัท

**สำคัญที่สุด ทำครั้งเดียวจบ** ถ้าไม่ทำ ใบเสนอราคาที่ส่งลูกค้าจะไม่มีชื่อบริษัท ที่อยู่ และเลขประจำตัวผู้เสียภาษีบนหัวกระดาษ

1. เมนูซ้าย → **ตั้งค่า** → แท็บ **บัญชีดีลเลอร์**
2. กรอกให้ครบ: ชื่อบริษัท · เลขประจำตัวผู้เสียภาษี · อีเมลบริษัท · โทรศัพท์ · เว็บไซต์ · ที่อยู่
3. กด **บันทึก** ที่มุมขวาบน

> ระบบจะเตือนให้เองตอนกำลังออกใบเสนอราคา ถ้ายังไม่ได้กรอกข้อมูลนี้

**เพิ่มรูปโปรไฟล์** — กดที่รูปวงกลมด้านบนของหน้าเดียวกัน เลือกไฟล์ภาพ แล้วกดบันทึก

---

## 3. ตั้งค่าเอกสารของสาขา (ทำครั้งเดียว)

**ตั้งค่า → ตั้งค่าใบเสนอราคา**

| ช่อง | ความหมาย |
|---|---|
| คำนำหน้าเลขที่ | ระบบกำหนดให้ แก้ไม่ได้ — เป็นรูปแบบเดียวกันทั้งเครือ |
| เลขลำดับถัดไป | ใบถัดไปจะเริ่มที่เลขนี้ · ตั้งได้เอง |
| ภาษีมูลค่าเพิ่ม % | ตั้งเองได้ (ปกติ 7) |
| อายุใบเสนอราคา | กี่วันที่ยืนราคา นับจากวันออกใบ |
| ตราประทับ / ลายเซ็น | อัปโหลดภาพ จะไปปรากฏท้ายใบเสนอราคา |
| เงื่อนไขท้ายเอกสาร | ข้อความที่พิมพ์ท้ายใบทุกใบ |

> % ภาษีจะถูกตรึงติดกับใบตั้งแต่วันที่ออก — แก้ค่านี้ทีหลังไม่กระทบใบที่ส่งลูกค้าไปแล้ว

---

## 4. เพิ่มรายชื่อพนักงานขาย (ผู้รับผิดชอบ)

**ตั้งค่า → ผู้รับผิดชอบ → ปุ่ม + เพิ่ม**

กรอกชื่อ-นามสกุล · ตำแหน่ง · โทรศัพท์ · อีเมล แล้วกดบันทึก

> คนกลุ่มนี้**ไม่ใช่ผู้ใช้ระบบ** เข้าระบบไม่ได้ — มีไว้เลือกว่าใครดูแลลูกค้ารายไหน เพื่อให้รายงานแยกตามคนได้

## 5. งานประจำวัน — เส้นทางการขายทั้งเส้น

```
ลูกค้าเป้าหมาย → ขอราคาจากสำนักงานใหญ่ → ได้ใบ HQ → ทำใบเสนอราคาให้ลูกค้า (บวก %) → ส่งให้ลูกค้า → ลูกค้าตอบรับ → กลายเป็นลูกค้า
```

> **ราคามาจากสำนักงานใหญ่เสมอ** — ดีลเลอร์ไม่ได้ตั้งราคาต่อหน่วยเองแล้ว สำนักงานใหญ่ตีราคาต้นทุนให้ทีละงาน (ใบ HQ)
> แล้วดีลเลอร์บวก % ของตัวเองเป็นราคาขาย

### 5.1 เพิ่มลูกค้าเป้าหมาย

เมนู **ลูกค้าเป้าหมาย** → ปุ่ม **+ เพิ่มลูกค้าเป้าหมาย**

ช่องที่ต้องกรอก: บริษัท · ผู้ติดต่อ · **โทรศัพท์** · **จังหวัดหน้างาน** (สองช่องนี้บังคับ) · พื้นที่ (ตร.ม.) · ผู้รับผิดชอบ
มูลค่าที่ประเมินกรอกเองได้ถ้ามี — มูลค่าจริงมาจากใบเสนอราคาภายหลัง

**ดูแบบตารางหรือแบบบอร์ดก็ได้** — ปุ่มสลับอยู่มุมขวาบนของตาราง แบบบอร์ดลากการ์ดข้ามคอลัมน์เพื่อเปลี่ยนสถานะได้เลย

### 5.2 ขอราคาจากสำนักงานใหญ่

1. คลิกที่ลูกค้าเป้าหมายรายนั้น → แท็บ **ใบเสนอราคา** → ปุ่ม **ขอราคาจาก HQ**
2. พิมพ์ **งานที่ขอราคา** (เช่น โกดังเก็บสินค้า 20x40 ม.) ใส่สเปก / รายละเอียดงาน → **ส่งคำขอ**
3. ลูกค้าเป้าหมายขึ้นสถานะ **รอราคา HQ** · แผงบอก **กำหนดส่งใบ HQ** (ภายใน 14 วัน)
4. ระหว่างรอ **ยกเลิกคำขอ** ได้ (ต้องใส่เหตุผล)
5. สำนักงานใหญ่ส่งใบ HQ แล้ว แถวของลูกค้าเป้าหมายขึ้นป้าย **ได้ราคาแล้ว** และเห็นใบ HQ ในแท็บใบเสนอราคา

### 5.3 ทำใบเสนอราคาให้ลูกค้าจากใบ HQ

1. แท็บ **ใบเสนอราคา** → ปุ่ม **ทำใบเสนอราคาจากใบ HQ**
2. รายการและจำนวนมาจากใบ HQ (แก้ไม่ได้) — ตั้ง **% ที่บวก** ได้รายบรรทัด
   ค่าตั้งต้นมาจาก **% บวกตั้งต้น** ที่ ตั้งค่า › ตั้งค่าใบเสนอราคา
3. ราคาขาย = ต้นทุนจากใบ HQ × (1 + %) — ระบบคิดให้ · อายุใบไม่เกินวันยืนราคาของใบ HQ
4. กด **สร้างใบเสนอราคา** — ระบบออกเลขที่ให้อัตโนมัติ
5. ต้องการราคาใหม่ → ปุ่ม **ขอแก้ราคา** สำนักงานใหญ่จะส่งใบ HQ เวอร์ชันใหม่ ใบเสนอราคาที่ทำจากเวอร์ชันเก่าปิดเองอัตโนมัติ

> หน้าพิมพ์และไฟล์ส่งออกที่ลูกค้าได้รับ **ไม่มีต้นทุนและ %** — มีแต่ราคาขาย

### 5.4 ส่งใบให้ลูกค้า และปิดการขาย

ที่หน้า **ใบเสนอราคา** คลิกใบที่ต้องการ แล้วใช้ปุ่มตามลำดับ

| ปุ่ม | ใช้เมื่อไหร่ |
|---|---|
| **พิมพ์ PDF** | ได้ไฟล์เอกสาร A4 พร้อมหัวกระดาษบริษัท ส่งลูกค้าได้เลย |
| **ส่งใบเสนอราคา** | เมื่อส่งให้ลูกค้าแล้ว — สถานะเปลี่ยนเป็น "ส่งแล้ว" |
| **ลูกค้าตอบรับ ✓** | ลูกค้าตกลงซื้อ — **ระบบสร้างลูกค้ารายนี้ให้อัตโนมัติ** นับเป็นยอดขาย และใบ HQ กลายเป็นคำสั่งผลิต (ราคาล็อก แก้ไม่ได้) |
| **ลูกค้าปฏิเสธ** | ลูกค้าไม่เอา — ต้องเลือกเหตุผลด้วย เพื่อให้สำนักงานใหญ่รู้ว่าเสียงานเพราะอะไร |
| **หมดอายุ** | เลยวันยืนราคาแล้วลูกค้ายังไม่ตอบ — ต้องการเสนอใหม่ให้ขอราคาจากสำนักงานใหญ่อีกครั้ง |

> กด "ลูกค้าตอบรับ" แล้วยอดจะขึ้นที่แดชบอร์ดของสาขาและของสำนักงานใหญ่ทันที ไม่ต้องแจ้งใคร

> **ใบเสนอราคาที่ออกก่อนเปลี่ยนมาใช้ใบ HQ** ยังอยู่ในระบบเป็นประวัติ — เปิดดูและพิมพ์ได้อย่างเดียว แก้/ลบ/ส่งไม่ได้

## 6. หน้าอื่นที่ใช้บ่อย

| เมนู | ใช้ทำอะไร |
|---|---|
| **แดชบอร์ด** | ดูยอดขายเทียบเป้าทั้งปี · งานที่ต้องตามวันนี้ · ลูกค้าที่เงียบนานเกินกำหนด |
| **ลูกค้า** | รายชื่อลูกค้าที่ปิดการขายได้แล้ว · ดูประวัติการซื้อย้อนหลัง · สร้างงานขายใหม่ให้ลูกค้าเดิม (แล้วขอราคาจากสำนักงานใหญ่) · นำเข้าลูกค้าเก่าจากไฟล์ (ดูข้อ 6.1) |
| **ปฏิทิน** | นัดหมายกับลูกค้า |
| **ไฟล์** | เอกสารที่แนบไว้กับลูกค้าเป้าหมาย/ลูกค้า · รองรับ PDF, Word, Excel, PowerPoint, CAD, รูปภาพ |

---

### 6.1 ย้ายลูกค้าเก่าเข้าระบบ (ทำครั้งเดียวตอนเริ่มใช้)

ลูกค้าที่ซื้อไปก่อนมีระบบนี้ ใส่เข้ามาได้เป็นชุด ไม่ต้องพิมพ์ทีละราย

1. เมนู **ลูกค้า** → ปุ่ม **นำเข้าลูกค้าเดิม**
2. กด **ดาวน์โหลดเทมเพลต (Excel)** จะได้ไฟล์ที่มีหัวคอลัมน์ครบและมีแถวตัวอย่างให้พิมพ์ทับ
3. กรอกข้อมูลลูกค้าลงไป (ลบบรรทัดตัวอย่างออกก่อน) แล้วบันทึกไฟล์
4. กลับมาที่หน้าเดิม กด **เลือกไฟล์** → ระบบแสดงรายชื่อให้ตรวจก่อนว่าจะเข้ากี่ราย → กดยืนยันนำเข้า

**ถ้ามีชื่อซ้ำกับลูกค้าที่มีอยู่แล้ว** ระบบจะเด้งถามก่อน เลือกได้ 3 ทาง
- **อัปเดตข้อมูล** — เติมเฉพาะช่องที่ของเดิมว่าง ข้อมูลเดิมที่มีอยู่ไม่ถูกทับ
- **แทนที่** — ใช้ข้อมูลจากไฟล์ทั้งหมด ทับของเดิม
- **ยกเลิก** — ไม่นำเข้าอะไรเลย

> รับไฟล์ Excel (.xlsx) · CSV · และไฟล์ที่ส่งออกจากระบบเก่า · วันที่เป็น พ.ศ. หรือ ค.ศ. ก็อ่านได้

---

### 6.2 ส่งออกตารางไปทำงานต่อ

ทุกหน้าที่มีตาราง (ลูกค้าเป้าหมาย · ใบเสนอราคา · ลูกค้า) มีปุ่ม **ส่งออก** มุมขวาบน เลือกได้ 3 แบบ

| แบบ | เอาไปทำอะไร |
|---|---|
| **Excel** | ไฟล์ .xlsx เปิดใน Excel / Google Sheets — ยอดเงินเป็นตัวเลขจริง รวมยอดและทำกราฟต่อได้ |
| **CSV** | เอาไปเข้าโปรแกรมอื่น |
| **PDF** | พิมพ์หรือส่งให้คนอื่นดู |

> ส่งออก = ทุกแถวที่กรองไว้อยู่ตอนนั้น ไม่ใช่เฉพาะหน้าที่เห็นบนจอ

## 7. ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ใบเสนอราคาไม่มีชื่อบริษัทบนหัวกระดาษ | ยังไม่ได้กรอกข้อมูลบริษัท → ตั้งค่า › บัญชีดีลเลอร์ (ดูข้อ 2) · ใบที่ออกไปแล้วจะยังว่างเหมือนเดิม เพราะระบบตรึงหัวกระดาษไว้กับใบตั้งแต่วันที่ออก |
| กดพิมพ์ PDF แล้วไม่มีอะไรขึ้น | เบราว์เซอร์บล็อกป๊อปอัป — กดอนุญาตป๊อปอัปสำหรับเว็บนี้ |
| ลืมรหัสผ่าน | ติดต่อสำนักงานใหญ่ให้ตั้งรหัสใหม่ให้ (ดูข้อ 1) |
| แก้ข้อมูลแล้วหาย | ตรวจว่ากด **บันทึก** ที่มุมขวาบนแล้วหรือยัง — หน้าตั้งค่าต้องกดบันทึกเสมอ |
| หน้าจอค้างตัวเลขเก่า | กด Ctrl+Shift+R เพื่อโหลดใหม่ทั้งหมด |

## 8. สิ่งที่ดีลเลอร์ทำไม่ได้ (ตามการออกแบบ)

- ตั้งราคาต่อหน่วยเอง หรือออกใบเสนอราคาโดยไม่มีใบ HQ — ราคาต้นทุนมาจากสำนักงานใหญ่ทีละงาน
- เห็นข้อมูลของสาขาอื่น — ระบบแยกข้อมูลรายสาขาเด็ดขาด
- เพิ่มผู้ใช้ระบบเพิ่ม — 1 ดีลเลอร์ = 1 บัญชี
