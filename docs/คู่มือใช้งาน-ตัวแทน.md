# คู่มือใช้งานสำหรับเซลส์ (ฝั่งดีลเลอร์)

อ่านครั้งเดียวจบ ใช้เวลาไม่เกิน 5 นาที · ทุกอย่างในระบบนี้วนอยู่รอบเรื่องเดียว
คือ **ลูกค้าเป้าหมาย → ใบเสนอราคา → ปิดการขาย**

---

## 1. เข้าระบบ

เปิดเว็บของดีลเลอร์ → กรอกอีเมลกับรหัสผ่านที่สำนักงานใหญ่ให้มา

- พิมพ์เว้นวรรคติดมาไม่เป็นไร ระบบตัดให้เอง
- ลืมรหัสผ่าน → ติดต่อสำนักงานใหญ่ (รีเซ็ตให้ได้ทันที)
- หนึ่งสาขา = หนึ่งบัญชี ทุกคนในสาขาใช้บัญชีเดียวกัน ส่วนชื่อ "ผู้รับผิดชอบ" เอาไว้ระบุว่างานนี้ใครดูแล

## 2. เพิ่มลูกค้าเป้าหมาย (คนที่สนใจ ยังไม่ซื้อ)

**ลูกค้าเป้าหมาย › เพิ่มลูกค้าเป้าหมาย**

ช่องที่ควรกรอกให้ครบ

| ช่อง | ทำไมสำคัญ |
|---|---|
| ชื่อบริษัท / ผู้ติดต่อ / เบอร์โทร | ใช้ตามงานและกันซ้ำกับที่มีอยู่ |
| **แม่แบบ** | ถ้าไม่เลือก จะออกใบเสนอราคาไม่ได้ (ระบบตั้งรายการสินค้าให้จากแม่แบบ) |
| **ประเมินราคา** | ระบบใช้คำนวณจำนวนตั้งต้นในใบเสนอราคา · พิมพ์ตัวเลขล้วน ลูกน้ำขึ้นให้เอง |
| พื้นที่ (ตร.ม.) | ถ้ารู้ ให้กรอก ระบบจะคิดจำนวนได้แม่นกว่าเดา |
| ขั้นตอน | เริ่มที่ "ติดต่อแล้ว" หรือ "รวบรวมความต้องการ" |

> ช่องไหนยังไม่รู้ ปล่อยเป็น "ยังไม่ระบุ" ได้ **อย่าเดาใส่** เพราะตัวเลขทั้งหมดวิ่งไปโผล่ในรายงานของสำนักงานใหญ่

## 3. ออกใบเสนอราคา

เปิดลูกค้าเป้าหมาย → แท็บ **ใบเสนอราคา** → **สร้างใบเสนอราคา**

- ระบบตั้งรายการสินค้าให้อัตโนมัติจากแม่แบบและราคาที่ประเมินไว้ · แก้จำนวนกับราคาต่อหน่วยได้
- **ราคาขายเป็นของสาขา** ตั้งเองได้อิสระ ไม่มีเพดาน (ราคาที่สำนักงานใหญ่ตั้งคือ "ราคากลาง" ไว้อ้างอิง)
- อยากบวกเพิ่มทุกแม่แบบทีเดียว → หน้า **แม่แบบ** ตั้งเปอร์เซ็นต์ไว้ล่วงหน้าได้
- ปุ่มบันทึกกดไม่ได้ = ระบบบอกเหตุผลไว้ข้าง ๆ ปุ่มเสมอ (ยังไม่มีรายการ · ยอดเป็น ฿0 · ยังไม่เลือกแม่แบบ)
- หนึ่งงานขาย = ใบเสนอราคาใบเดียว แก้ใบเดิมได้ ระบบเก็บเป็นฉบับ V2 V3 ให้เอง

## 4. ตามงานอย่าให้หลุด

- **ปฏิทิน** — ลงนัดหมายไว้ ระบบเตือนให้
- ลูกค้าเป้าหมายที่เงียบเกินกำหนดจะขึ้นเตือนที่กระดิ่ง และโผล่ในรายงานของสำนักงานใหญ่ด้วย
- ทุกครั้งที่คุยกับลูกค้า บันทึกกิจกรรมไว้ — เดือนหน้าจะจำไม่ได้ว่าคุยอะไรไว้

## 5. ปิดการขาย

เปิดใบเสนอราคา → **ปิดการขายสำเร็จ**

- ระบบจะย้ายลูกค้ารายนี้เข้าฐานลูกค้าและบวกยอดให้อัตโนมัติ
- ปิดแล้ว **ย้อนกลับไม่ได้** ตรวจยอดให้ดีก่อนกด
- ถ้าไม่สำเร็จ ให้กด **ปิดการขายไม่สำเร็จ** แล้วเลือกเหตุผล — สำนักงานใหญ่เอาไปสรุปว่าเสียงานเพราะอะไรบ้าง อย่าปล่อยค้างไว้เฉย ๆ

## 6. ดูผลงานตัวเอง

**แดชบอร์ด** — ยอดสะสมทั้งปีเทียบเป้าที่สำนักงานใหญ่ตั้งไว้ · งานที่ต้องตามด่วน · กราฟยอดขาย

แถบเลือกช่วงเวลาด้านบนคุมกราฟและการ์ดส่วนใหญ่
เลือก "วันนี้" → กราฟแยกเป็นรายชั่วโมง · เลือกช่วงยาว → แยกเป็นรายวันหรือรายเดือน
**การ์ดเป้าหมายทั้งปีจะไม่เปลี่ยนตามช่วงเวลา** เพราะเป้าเป็นของทั้งปีเสมอ

## เจอปัญหาบ่อย ๆ

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ปุ่ม "สร้างใบเสนอราคา" กดไม่ได้ | งานขายยังไม่ได้เลือกแม่แบบ หรือยอดรวมเป็น ฿0 — ดูข้อความสีแดงข้างปุ่ม |
| ตารางรายการสินค้าว่างเปล่า | ยังไม่ได้เลือกแม่แบบให้งานขายนั้น |
| ราคาต่อหน่วยไม่ใช่ราคาที่อยากได้ | ตั้งเปอร์เซ็นต์บวกเพิ่มที่หน้าแม่แบบ หรือแก้ราคาในใบตรง ๆ ก็ได้ |
| เข้าระบบไม่ได้ | อีเมลหรือรหัสผิด — ให้สำนักงานใหญ่รีเซ็ตให้ |
| ตัวเลขบนจอไม่ตรงกับที่คิดไว้ | ดูแถบช่วงเวลาด้านบนก่อน อาจกำลังดูอยู่คนละช่วง |
